Used as internal/assets/textures/story-flame-anim.png
(internal/assets.StoryFlameAnimation), the flickering flame billboard
behind Ganon on the story screen background (cmd/story,
internal/renderer/story.go).

Original file is a 100x156px sprite sheet, grid of 10 columns x 6 rows,
each frame 10x26px (orange fire color variant, one of three colors in
the pack). Only the first row (10 frames) is used as the animation loop.
