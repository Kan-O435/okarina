Used as internal/assets/models/temple-tree.glb (internal/assets.TempleTree),
the tree model for the temple field (cmd/game / internal/renderer/demo.go's
treeObjects). Replaces the previous CC0 Gobkit Nature Kit low-poly trees for
this field only; grassland/ganon fields are unaffected and continue to use
internal/assets.Trees (Gobkit).

Single mesh with an embedded base color texture, loaded with the ordinary
LoadGLBMesh path (no skin, no parts split).
